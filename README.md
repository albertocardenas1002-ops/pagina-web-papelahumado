# 🚗 Papel Ahumado & Papel de Seguridad | Alberto Cárdenas

Sitio web oficial y landing page profesional diseñada para el negocio de instalación a domicilio de papel ahumado y láminas de seguridad automotriz en Caracas, Venezuela. 

El proyecto cuenta con una trayectoria de más de 25 años respaldando acabados impecables en vehículos particulares y camionetas.

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica de las secciones.
* **CSS3:** Diseño responsivo (Mobile-First), uso de Grid/Flexbox y compatibilidad con pantallas móviles.
* **JavaScript:** Control dinámico de navegación entre secciones sin recargar la página.
* **FontAwesome:** Iconografía moderna para botones y tarjetas.
* **Git & GitHub:** Control de versiones y repositorio de código.
* **Netlify:** Alojamiento web y despliegue continuo.

---

## 📱 Características del Sitio
* **Diseño 100% Responsivo:** Adaptado de forma óptima para teléfonos inteligentes, tabletas y computadoras de escritorio.
* **Sección de Inicio / Presentación:** Resumen de la experiencia del especialista Alberto Cárdenas.
* **Soluciones Automotrices:** Detalle de tecnologías Nano-Carbón, Nano-Cerámica y láminas anti-impacto.
* **Guía de Tonalidades:** Explicación de los niveles de oscuridad (5%, 20%, 35%) disponibles.
* **Galería de Resultados:** Demostración visual de "Antes y Después" en carros y camionetas.
* **Sección de Testimonios:** Opiniones reales de clientes satisfechos.
* **Contacto Directo:** Enlaces integrados y botón flotante directo a WhatsApp para cotizaciones rápidas en Caracas.
